This is just a prototype version of the UI that will do most of the work on this app. 
It's not exactly intuitive yet and does not have any of the functionality of having a sensor input (that can be considered later) 
but it does have an area to calibrate such, so you can mess around with that to check how it affects the way food expires.
We can obviously add more features later.. but this is it for now, if you have any suggestions you should tell us.

Enter this into the terminal:
npm install --legacy-peer-deps && npm run dev


In the bottom right, you will see a prompt to go to port 3000
Here, click "Open in Browser"
